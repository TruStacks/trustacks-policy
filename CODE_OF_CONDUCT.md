# Code of Conduct

This project adopts the **[Contributor Covenant version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** in full as its code of conduct. The canonical text — including the standards, scope, and enforcement guidelines — lives at the URL above and applies verbatim to participation in this repository.

By contributing to `trustacks-policy` (issues, pull requests, discussions, reviews, or any other form of project participation), you agree to abide by Contributor Covenant 2.1.

## Scope

The code applies to all project spaces: this GitHub repository, any associated chat / forum spaces TruStacks operates, and public spaces when an individual is officially representing the project.

## Reporting

Reports of conduct violations should be sent to **conduct@trustacks.com**. Reports are reviewed by the TruStacks maintainer team and handled confidentially. We aim to acknowledge reports within 2 business days and resolve within 14.

The Contributor Covenant's *Enforcement Guidelines* (correction → warning → temporary ban → permanent ban) apply.
